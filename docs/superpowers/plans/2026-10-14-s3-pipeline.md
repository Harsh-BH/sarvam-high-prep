# S3 ingestion + cleaning pipeline: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement your lane's tasks in order. Steps use checkbox (`- [ ]`) syntax for tracking. The master session reviews each lane before merging it.

**Goal:** the storage layer, launcher, archive, ingestion, rebuild and two new cleaning stages from the design, working end to end on the 40-clip pilot.

**Architecture:** plain Python CLIs in `pipeline/`, one per responsibility, talking to one S3 bucket through `pipeline/s3.py`. Stages keep the SPEC §8 JSONL contract; `pipeline/run.py` runs any stage locally or as a SageMaker training job and only advances `LATEST` when `validate.py --partial` passes.

**Tech Stack:** Python 3.12+ via `uv` with PEP 723 script headers (like `validate.py`); boto3 (the S3/SageMaker SDK; the aws CLI already uses the same botocore); numpy (FFT and frame statistics in `audio_qc.py`); a pinned static ffmpeg n9.0.x with libsoxr.

**Spec:** `docs/superpowers/specs/2026-10-14-s3-ingestion-cleaning-design.md`. Read it before your lane. Also `SPEC.md` (data contract) and `validate.py`.

## Global Constraints

- Bucket `sarvam-parta-114872709824`, region `ap-south-1`. Credentials: `AWS_PROFILE=harsh-admin` (in `.env`); SageMaker jobs use role `arn:aws:iam::114872709824:role/sarvam-sm-role`.
- Use only `pipeline/s3.py` for S3 (`put_once`, `put`, `get`, `exists`, `keys`, `download`, `upload_dir`). Writes under `archive/` must use `put_once` (the bucket policy refuses anything else). `raw/` and `release/` writes also use `put_once`.
- Tests are plain `pipeline/test_*.py` scripts with `assert`s, run with `uv run pipeline/test_<x>.py`, using `FakeS3` from `pipeline/test_s3.py`. No test framework. A `--live` flag may add a real-bucket check under `stages/_selftest/` and must clean up after itself.
- Stage CLI contract: `uv run <script> --in RECORDS.jsonl --audio-dir DIR --out OUT_DIR [stage params]`. Writes `OUT_DIR/records.jsonl`, `OUT_DIR/rejects.jsonl` (one `{"id","stage","rule","detail"}` per excluded record) and `OUT_DIR/audio/` only if the stage makes audio. Resumable: ids already in `OUT_DIR/records.jsonl` or `rejects.jsonl` are skipped on re-run. Records follow SPEC §8 (internal fields start with `_`).
- Run id: `YYYYMMDDTHHMMSSZ-<git short sha>` (UTC).
- Never print secrets. Never publish anything (§10 R3). Never re-synthesise TTS (CLAUDE.md).
- In shell strings brace variables before a colon: `${VAR}:x`, never `$VAR:x` (zsh modifiers corrupt it).
- Python files: compact, stdlib first, match `validate.py`'s style. A deliberate shortcut gets a `# ponytail:` comment naming its ceiling.
- Commit after each task on your lane branch, with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push, never touch `main`, never edit files outside your task's **Files** list.

## Review Focus

1. **Re-running after a crash** must neither duplicate nor lose records: a partially written `OUT_DIR` resumes with only the missing ids (Task 3 test `resume`).
2. **Two processes archiving the same request**: the loser of `put_once` must return the winner's stored response, not its own (Task 2 test `race`).
3. **A failed stage must not advance `LATEST`**: non-zero exit or any validator violation leaves `LATEST` unchanged and still uploads the run for inspection (Task 3 test `latest_guard`).
4. **Upstream source changed** (IndicVoices archive ETag differs from the pinned one): ingest refuses instead of silently storing different bytes (Task 6 test `etag_guard`).
5. **SageMaker running code that isn't committed**: `--sm` refuses a dirty working tree, so every job maps to one git sha (Task 4 test `dirty_tree`).

## Not in this plan (deliberately)

- `data_card.md` generation from `pipeline/corpora.json`, and the W5/W6/W7 stages: same stage contract, separate plans.

```python
"""archive_call: every paid API call goes through here (design §2.2). Never pays twice, never loses a paid output."""
import hashlib, json, time
from datetime import datetime, timezone
from pathlib import Path
import s3 as store

SPOOL = Path(__file__).resolve().parent.parent / "data/archive_spool"  # local write-ahead copy, survives a crash
_spent = {}  # stream -> INR, filled lazily from the archive


class SpendCapError(Exception):
    pass


def request_key(request):
    return hashlib.sha256(json.dumps(request, sort_keys=True, ensure_ascii=False, separators=(",", ":")).encode()).hexdigest()


def _load(service, key, s3=None):
    meta = store.get(f"archive/api/{service}/{key}.json", s3)
    if meta is None:
        return None
    meta = json.loads(meta)
    payload = store.get(f"archive/api/{service}/{meta['payload']}", s3) if meta.get("payload") else None
    return meta["response"], payload


def spent(stream, s3=None):
    if stream not in _spent:
        # ponytail: one GET per archived call, fine for a few thousand calls; keep a spend index if it gets slow
        total = 0.0
        for k in store.keys("archive/api/", s3):
            if k.endswith(".json"):
                m = json.loads(store.get(k, s3))
                total += m.get("inr", 0) if m.get("stream") == stream else 0
        _spent[stream] = total
    return _spent[stream]


def _upload(service, key, meta_bytes, payload, s3=None):
    """-> True if our copy is now the archived one, False if another writer got there first."""
    if payload is not None:
        store.put_once(f"archive/api/{service}/{key}.bin", payload, s3)
    return store.put_once(f"archive/api/{service}/{key}.json", meta_bytes, s3)


def flush_spool(s3=None, spool=SPOOL):
    n = 0
    for p in sorted(Path(spool).glob("*/*.json")):
        service, key = p.parent.name, p.stem
        b = p.with_suffix(".bin")
        _upload(service, key, p.read_bytes(), b.read_bytes() if b.exists() else None, s3)
        p.unlink()
        b.unlink(missing_ok=True)
        n += 1
    return n


def archive_call(service, request, call, *, stream, inr, cap_inr, s3=None, spool=SPOOL, retries=4, sleep=time.sleep):
    key = request_key(request)
    hit = _load(service, key, s3)
    if hit is not None:
        return hit
    if spent(stream, s3) + inr > cap_inr:
        raise SpendCapError(f"{stream}: {spent(stream, s3):.2f} + {inr:.2f} INR > cap {cap_inr:.2f}")
    for attempt in range(retries + 1):
        try:
            response, payload = call(request)
            break
        except Exception:
            if attempt == retries:
                raise
            sleep(2 ** attempt)
    meta = json.dumps({"service": service, "request": request, "response": response, "stream": stream, "inr": inr,
                       "at": datetime.now(timezone.utc).isoformat(timespec="seconds"),
                       "payload": f"{key}.bin" if payload is not None else None}, ensure_ascii=False).encode()
    d = Path(spool) / service
    d.mkdir(parents=True, exist_ok=True)
    if payload is not None:
        (d / f"{key}.bin").write_bytes(payload)
    (d / f"{key}.json").write_bytes(meta)  # written last: its presence means the spool entry is complete
    won = _upload(service, key, meta, payload, s3)
    (d / f"{key}.json").unlink()
    (d / f"{key}.bin").unlink(missing_ok=True)
    _spent[stream] = spent(stream, s3) + inr
    return (response, payload) if won else _load(service, key, s3)
```

# /// script
# requires-python = ">=3.12"
# dependencies = ["boto3"]
# ///
"""Run one pipeline stage locally or on SageMaker (design §4.1). LATEST moves only on a clean, validated run.

    uv run pipeline/run.py <stage> --in <stage>|stages/<stage>/<run> [--audio-from ...] [--local | --sm INSTANCE [--spot]] [-- params]
"""
import argparse, json, subprocess, sys
from datetime import datetime, timezone
from pathlib import Path
import s3 as store

ROOT = Path(__file__).resolve().parent.parent
CACHE = ROOT / "data/cache"
VALIDATE = ["uv", "run", str(ROOT / "validate.py")]
STAGES = {
    "audio_qc": {"cmd": ["uv", "run", str(ROOT / "pipeline/audio_qc.py")], "makes_audio": False, "gpu": False},
    "dedupe": {"cmd": ["uv", "run", str(ROOT / "pipeline/dedupe.py")], "makes_audio": False, "gpu": False},
}


def run_id(git_sha, now):
    return f"{now:%Y%m%dT%H%M%SZ}-{git_sha}"


def git_sha():
    return subprocess.run(["git", "-C", str(ROOT), "rev-parse", "--short", "HEAD"], capture_output=True, text=True, check=True).stdout.strip()


def latest(stage, s3=None):
    b = store.get(f"stages/{stage}/LATEST", s3)
    return b.decode().strip() if b else None


def resolve(ref, s3=None):
    """'<stage>' or 'stages/<stage>/<run>' -> 'stages/<stage>/<run>'."""
    if ref.startswith("stages/"):
        return ref.rstrip("/")
    r = latest(ref, s3)
    if r is None:
        raise SystemExit(f"no LATEST run for stage {ref!r}")
    return f"stages/{ref}/{r}"


def _count(p):
    return sum(1 for l in open(p) if l.strip()) if p.exists() else 0


def run_local(stage, spec, in_records, audio_prefix, params, *, run, cache=CACHE, s3=None, validate_cmd=VALIDATE):
    work = Path(cache) / stage / run
    inp, out = work / "in" / "records.jsonl", work / "out"  # out/ survives a crash: the stage resumes into it
    inp.parent.mkdir(parents=True, exist_ok=True)
    out.mkdir(parents=True, exist_ok=True)
    inp.write_bytes(store.get(in_records, s3))
    audio = Path(cache) / "audio" / audio_prefix.strip("/").replace("/", "_")
    store.download(audio_prefix, audio, s3)  # shared cache across runs; skips files already present
    started = datetime.now(timezone.utc).isoformat(timespec="seconds")
    rc = subprocess.run(spec["cmd"] + ["--in", str(inp), "--audio-dir", str(audio), "--out", str(out)] + params).returncode
    violations = None
    if rc == 0:
        v = subprocess.run(validate_cmd + [str(out / "records.jsonl"), "--audio-dir", str(out if spec["makes_audio"] else audio), "--partial"],
                           capture_output=True, text=True)
        violations = sum(1 for l in v.stdout.splitlines() if l.strip()) if v.returncode else 0
        (out / "validate.txt").write_text(v.stdout + v.stderr)
    prefix = f"stages/{stage}/{run}"
    store.upload_dir(out, prefix, s3)
    meta = {"stage": stage, "run": run, "input": in_records, "audio_from": audio_prefix, "params": params, "where": "local",
            "started": started, "finished": datetime.now(timezone.utc).isoformat(timespec="seconds"), "exit": rc,
            "violations": violations, "records": _count(out / "records.jsonl"), "rejects": _count(out / "rejects.jsonl")}
    store.put(f"{prefix}/run.json", json.dumps(meta, indent=1).encode(), s3)
    if rc != 0:
        return 1
    if violations:
        return 2
    store.put(f"stages/{stage}/LATEST", run.encode(), s3)
    return 0


def main():
    argv = sys.argv[1:]
    params = argv[argv.index("--") + 1:] if "--" in argv else []
    argv = argv[:argv.index("--")] if "--" in argv else argv
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("stage", choices=sorted(STAGES))
    ap.add_argument("--in", dest="inp", required=True)
    ap.add_argument("--audio-from")
    ap.add_argument("--run", help="resume this run id instead of starting a new one")
    g = ap.add_mutually_exclusive_group()
    g.add_argument("--local", action="store_true")
    g.add_argument("--sm", metavar="INSTANCE")
    ap.add_argument("--spot", action="store_true")
    a = ap.parse_args(argv)

from pathlib import Path
import s3 as store

ROOT = Path(__file__).resolve().parent.parent
IMAGE_GPU = "763104351884.dkr.ecr.ap-south-1.amazonaws.com/pytorch-training:2.9.0-gpu-py312-cu130-ubuntu22.04-sagemaker-v2.2-2026-09-07-22-13-38"

                               capture_output=True, text=True, check=True).stdout.strip())


def job_request(stage, src, audio_src, params, *, run, sha, instance, spot):
    b = store.BUCKET
    name = re.sub(r"[^A-Za-z0-9-]", "-", f"sarvam-{stage}-{run}")[:63].rstrip("-")
    req = {
        "TrainingJobName": name,
        "AlgorithmSpecification": {"TrainingImage": IMAGE_GPU if instance.startswith(GPU_FAMILIES) else IMAGE_CPU,
                                   "TrainingInputMode": "File"},
        "RoleArn": ROLE,
        "HyperParameters": {"sagemaker_program": "pipeline/sm_entry.py",
                            "sagemaker_submit_directory": f"s3://{b}/code/{sha}.tar.gz",
                            "stage": stage, "src": src, "audio_src": audio_src, "run": run, "params": json.dumps(params)},
        "OutputDataConfig": {"S3OutputPath": f"s3://{b}/stages/_sm_output/"},
        "ResourceConfig": {"InstanceType": instance, "InstanceCount": 1, "VolumeSizeInGB": 100},
        "StoppingCondition": {"MaxRuntimeInSeconds": 6 * 3600},
        "CheckpointConfig": {"S3Uri": f"s3://{b}/stages/{stage}/{run}/_ckpt/", "LocalPath": "/opt/ml/checkpoints"},
        "Environment": {"AWS_DEFAULT_REGION": store.REGION},
        "Tags": [{"Key": "project", "Value": "sarvam-parta"}],
    }
    if spot:
        req["EnableManagedSpotTraining"] = True
        req["StoppingCondition"]["MaxWaitTimeInSeconds"] = 12 * 3600
    return req

    if _dirty():
        print("refusing: commit first, a job must map to one git sha", file=sys.stderr)
        return 3
    sha = subprocess.run(["git", "-C", str(ROOT), "rev-parse", "--short", "HEAD"], capture_output=True, text=True, check=True).stdout.strip()

        import boto3
        sagemaker = boto3.client("sagemaker", region_name=store.REGION)
    req = job_request(stage, src, audio_src, params, run=run, sha=sha, instance=instance, spot=spot)
    sagemaker.create_training_job(**req)
    print(f"submitted {req['TrainingJobName']}; logs: /aws/sagemaker/TrainingJobs/{req['TrainingJobName']}", file=sys.stderr)
    while True:
        d = sagemaker.describe_training_job(TrainingJobName=req["TrainingJobName"])
        if d["TrainingJobStatus"] in ("Completed", "Failed", "Stopped"):
            print(d["TrainingJobStatus"], d.get("FailureReason", ""), file=sys.stderr)
            return 0 if d["TrainingJobStatus"] == "Completed" else 1

"""The one ffmpeg every cut and rebuild uses (design §4.1). Byte-identical audio depends on it."""
import hashlib, subprocess, tarfile, wave
from pathlib import Path
import s3 as store

TOOLS = Path(__file__).resolve().parent.parent / "data/tools"
VERSION = "n9.0.x"            # set from Step 1
TOOL_KEY = "raw/_tools/..."   # set from Step 1 (source URL in a comment here)
TOOL_SHA256 = "..."           # set from Step 1
RATE = 24000


def binary(s3=None):
    tgz = TOOLS / Path(TOOL_KEY).name
    if not tgz.exists():
        TOOLS.mkdir(parents=True, exist_ok=True)
        tgz.write_bytes(store.get(TOOL_KEY, s3))
    if hashlib.sha256(tgz.read_bytes()).hexdigest() != TOOL_SHA256:
        raise SystemExit(f"{tgz}: sha256 mismatch, refusing to cut with an unpinned ffmpeg")
    dest = TOOLS / tgz.name.split(".tar")[0]
    if not dest.exists():
        with tarfile.open(tgz) as t:
            t.extractall(TOOLS, filter="data")
    return next(dest.rglob("bin/ffmpeg"))


def cut(src, start, end, out, s3=None):
    a, b = round(start * 1000) * RATE // 1000, round(end * 1000) * RATE // 1000
    subprocess.run([str(binary(s3)), "-nostdin", "-v", "error", "-y", "-i", str(src), "-af",
                    f"aresample={RATE}:resampler=soxr,atrim=start_sample={a}:end_sample={b}",
                    "-ac", "1", "-c:a", "pcm_s16le", "-fflags", "+bitexact", "-flags:a", "+bitexact", str(out)], check=True)
    with wave.open(str(out)) as w:
        assert (w.getframerate(), w.getnchannels(), w.getsampwidth(), w.getnframes()) == (RATE, 1, 2, b - a), out

"""Ingest the IndicVoices source files we cut from into raw/, pinned and verifiable (design §2.1).

    uv run pipeline/ingest_iv.py --records data/w1/pool/manifest.jsonl [--local data/w1/iv_train]
    uv run pipeline/ingest_iv.py --verify

import argparse, collections, hashlib, json, sys, tarfile, urllib.request
from datetime import datetime, timezone
from pathlib import Path
import s3 as store

CORPORA = json.loads((Path(__file__).resolve().parent / "corpora.json").read_text())


def gate(corpus):
    st = CORPORA.get(corpus, {}).get("status")
    if st != "OK":
        raise SystemExit(f"{corpus}: catalog status {st!r}, ingestion refused (design §2.1)")


def _put(member, data, url, etag, s3):
    key = f"raw/indicvoices/{member}"
    if store.exists(key + ".meta.json", s3):
        return 0
    store.put_once(key, data, s3)
    side = {"corpus": "indicvoices", "url": url, "etag": etag, "member": member, "sha256": hashlib.sha256(data).hexdigest(),
            "size": len(data), "fetched_at": datetime.now(timezone.utc).isoformat(timespec="seconds")}
    store.put_once(key + ".meta.json", json.dumps(side).encode(), s3)
    return 2


def ingest(wanted, *, rev, s3=None, opener=urllib.request.urlopen, local=None):
    gate("indicvoices")
    n = 0
    for url, members in wanted.items():
        want = set(members) | {m.rsplit(".", 1)[0] + ".json" for m in members}
        if local:
            for m in sorted(want):
                p = Path(local) / Path(m).name
                if p.exists():
                    n += _put(m, p.read_bytes(), url, rev[url], s3)
            continue
        with opener(url) as r:
            etag = r.headers.get("ETag", "").strip('"')
            if etag != rev[url]:
                raise SystemExit(f"{url}: ETag {etag!r} != pinned {rev[url]!r}; upstream changed, refusing")
            with tarfile.open(fileobj=r, mode="r|gz") as t:
                for ti in t:
                    if ti.name in want:
                        n += _put(ti.name, t.extractfile(ti).read(), url, etag, s3)
                        want.discard(ti.name)
                        if not want:
                            break
    return n


def verify(prefix="raw/indicvoices/", s3=None):
    bad = []
    for k in store.keys(prefix, s3):
        if k.endswith(".meta.json"):
            continue
        side = store.get(k + ".meta.json", s3)
        if side is None or hashlib.sha256(store.get(k, s3)).hexdigest() != json.loads(side)["sha256"]:
            bad.append(k)

# /// script
# requires-python = ">=3.12"
# dependencies = ["boto3"]

"""Freeze a release snapshot in S3 (design §1 release/, SPEC §6 serialisation).

    uv run pipeline/release.py <tag> --records A.jsonl [B.jsonl ...] --audio-dir DIR [--partial]
"""
import argparse, json, subprocess, sys, tempfile
from pathlib import Path
import s3 as store

ROOT = Path(__file__).resolve().parent.parent
KEYS = ["id", "audio", "duration", "speaker_id", "source", "sentences", "hi_words", "translation_method"]


def _strip(x):
    if isinstance(x, dict):
        return {k: _strip(v) for k, v in x.items() if not k.startswith("_")}
    if isinstance(x, list):
        return [_strip(v) for v in x]
    return round(x, 3) if isinstance(x, float) else x


def serialise(rec):
    r = _strip(rec)
    return json.dumps({k: r[k] for k in KEYS if k in r}, ensure_ascii=False)


def merge(stage_files):
    by = {}
    for p in stage_files:
        for l in open(p, encoding="utf-8"):
            if l.strip():
                rec = json.loads(l)
                by.setdefault(rec["id"], {}).update(rec)
    return [by[k] for k in sorted(by)]


def snapshot(tag, stage_files, audio_dir, *, partial, s3=None):
    if store.exists(f"release/{tag}/manifest.jsonl", s3):
        raise SystemExit(f"release/{tag} exists; releases are frozen, pick a new tag")
    recs = merge(stage_files)
    body = "".join(serialise(r) + "\n" for r in recs)
    with tempfile.NamedTemporaryFile("w", suffix=".jsonl", delete=False, encoding="utf-8") as t:
        t.write(body)
    v = subprocess.run(["uv", "run", str(ROOT / "validate.py"), t.name, "--audio-dir", str(audio_dir)] + (["--partial"] if partial else []))
    if v.returncode:
        raise SystemExit("validate.py failed; nothing released")
    for r in recs:
        store.put_once(f"release/{tag}/audio/{r['id']}.wav", (Path(audio_dir) / r["audio"]).read_bytes(), s3)
    prov = "".join(json.dumps({"id": r["id"], "_rev": r.get("_rev"), "_archive": r.get("_archive"),
                               "stage_files": [str(p) for p in stage_files]}, ensure_ascii=False) + "\n" for r in recs)
    store.put_once(f"release/{tag}/provenance.jsonl", prov.encode(), s3)
    store.put_once(f"release/{tag}/manifest.jsonl", body.encode(), s3)  # last: its presence marks a complete release
    return len(recs)


def main():
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("tag")
    ap.add_argument("--records", nargs="+", type=Path, required=True)
    ap.add_argument("--audio-dir", type=Path, required=True)
    ap.add_argument("--partial", action="store_true")
    a = ap.parse_args()
    print(f"release/{a.tag}: {snapshot(a.tag, a.records, a.audio_dir, partial=a.partial)} records")


if __name__ == "__main__":
    main()

"""Rebuild a release from raw/ + archive/ + stage files and compare byte-for-byte (§3A, design §4.2).

    uv run pipeline/rebuild.py <tag>
"""
import hashlib, json, sys
from pathlib import Path
import ffmpeg, release, s3 as store

ROOT = Path(__file__).resolve().parent.parent


def rebuild(tag, *, s3=None, work=ROOT / "data/rebuild"):
    work = Path(work) / tag
    work.mkdir(parents=True, exist_ok=True)
    manifest = store.get(f"release/{tag}/manifest.jsonl", s3).decode().splitlines()
    prov = {p["id"]: p for p in map(json.loads, store.get(f"release/{tag}/provenance.jsonl", s3).decode().splitlines())}
    same, diff = 0, []
    for line in manifest:
        r = json.loads(line)
        want = store.get(f"release/{tag}/audio/{r['id']}.wav", s3)
        if r["source"]["synthetic"]:
            got = store.get(prov[r["id"]]["_archive"]["tts"], s3)  # the archived take; never re-synthesised
        else:
            key = f"raw/{r['source']['source_file']}"
            src = work / "raw" / r["source"]["source_file"]
            if not src.exists():
                src.parent.mkdir(parents=True, exist_ok=True)
                src.write_bytes(store.get(key, s3))
            if hashlib.sha256(src.read_bytes()).hexdigest() != json.loads(store.get(key + ".meta.json", s3))["sha256"]:
                raise SystemExit(f"{key}: sha256 differs from its sidecar")
            out = work / f"{r['id']}.wav"
            ffmpeg.cut(src, r["source"]["start"], r["source"]["end"], out)
            got = out.read_bytes()
        if got == want:
            same += 1
        else:
            diff.append(r["id"])
    files = next(iter(prov.values()))["stage_files"] if prov else []
    remade = [release.serialise(x) for x in release.merge([Path(p) for p in files])] if files and all(Path(p).exists() for p in files) else None
    return {"records": len(manifest), "audio_identical": same, "audio_diff": diff, "manifest_identical": remade == manifest}


def main():
    rep = rebuild(sys.argv[1])
    print(json.dumps(rep, indent=1))
    sys.exit(0 if not rep["audio_diff"] and rep["manifest_identical"] else 1)


if __name__ == "__main__":
    main()

```python
# /// script
# requires-python = ">=3.12"
# dependencies = ["numpy"]
# ///
"""C4 audio QC stage (design §3.1): measure every clip, reject clear outliers, label telephone audio.

    uv run pipeline/audio_qc.py --in RECORDS.jsonl --audio-dir DIR --out OUT_DIR [--max-clip-ratio X ...]
"""
import argparse, json, wave
from pathlib import Path
import numpy as np

DEFAULTS = {"max_clip_ratio": 0.001, "max_silence_ratio": 0.5, "min_rms_dbfs": -40.0, "min_snr_db": 10.0, "min_dur": 10.0, "max_dur": 60.0}
ORDER = ["clipping", "silence", "level", "snr", "duration"]


def _db(x):
    return 20 * np.log10(np.maximum(x, 1e-9) / 32768)


def measure(path):
    with wave.open(str(path)) as w:
        sr, x = w.getframerate(), np.frombuffer(w.readframes(w.getnframes()), "<i2").astype(np.float64)
    hop = sr // 50
    frames = x[: len(x) // hop * hop].reshape(-1, hop)
    fdb = _db(np.sqrt((frames ** 2).mean(axis=1))) if len(frames) else np.array([-180.0])
    spec = np.abs(np.fft.rfft(x)) ** 2
    hf = spec[np.fft.rfftfreq(len(x), 1 / sr) > 4000].sum() / max(spec.sum(), 1e-9)
    return {"duration": len(x) / sr, "rms_dbfs": float(_db(np.sqrt((x ** 2).mean()) if len(x) else 0)),
            "clip_ratio": float((np.abs(x) >= 32767).mean()) if len(x) else 0.0,
            "silence_ratio": float((fdb < -50).mean()), "snr_db": float(np.percentile(fdb, 90) - np.percentile(fdb, 10)),
            "hf_ratio": float(hf), "telephone": bool(hf < 0.01)}


def verdict(m, t):
    fail = {"clipping": m["clip_ratio"] > t["max_clip_ratio"], "silence": m["silence_ratio"] > t["max_silence_ratio"],
            "level": m["rms_dbfs"] < t["min_rms_dbfs"], "snr": m["snr_db"] < t["min_snr_db"],
            "duration": not t["min_dur"] <= m["duration"] <= t["max_dur"]}
    return [r for r in ORDER if fail[r]]


def main():
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--in", dest="inp", type=Path, required=True)
    ap.add_argument("--audio-dir", type=Path, required=True)
    ap.add_argument("--out", type=Path, required=True)
    for k, v in DEFAULTS.items():
        ap.add_argument("--" + k.replace("_", "-"), type=float, default=v)
    a = ap.parse_args()
    t = {k: getattr(a, k) for k in DEFAULTS}
    a.out.mkdir(parents=True, exist_ok=True)
    done = {json.loads(l)["id"] for f in ("records.jsonl", "rejects.jsonl") if (a.out / f).exists() for l in open(a.out / f)}
    with open(a.out / "records.jsonl", "a", encoding="utf-8") as ok, open(a.out / "rejects.jsonl", "a", encoding="utf-8") as bad:
        for l in open(a.inp, encoding="utf-8"):
            rec = json.loads(l)
            if rec["id"] in done:
                continue
            m = measure(a.audio_dir / rec["audio"])
            fails = verdict(m, t)
            if fails:
                bad.write(json.dumps({"id": rec["id"], "stage": "audio_qc", "rule": fails[0], "detail": {"failed": fails, **m}}) + "\n")
            else:
                rec.setdefault("_qa", {})["audio_qc"] = m
                ok.write(json.dumps(rec, ensure_ascii=False) + "\n")


if __name__ == "__main__":
    main()

# /// script
# requires-python = ">=3.12"
# ///
"""C5 dedupe stage (design §3.1): drop exact re-cuts and byte-identical audio; keep the lowest id.

    uv run pipeline/dedupe.py --in RECORDS.jsonl --audio-dir DIR --out OUT_DIR
"""
import argparse, hashlib, json
from pathlib import Path


def run(records, audio_dir):
    kept, rejects, seen_iv, seen_sha = [], [], {}, {}
    for r in sorted(records, key=lambda r: r["id"]):
        s = r["source"]
        iv = (s["source_file"], round(s["start"], 3), round(s["end"], 3))
        sha = hashlib.sha256((Path(audio_dir) / r["audio"]).read_bytes()).hexdigest()
        if iv in seen_iv:
            rejects.append({"id": r["id"], "stage": "dedupe", "rule": "same_interval", "detail": f"same as {seen_iv[iv]}"})
        elif sha in seen_sha:
            rejects.append({"id": r["id"], "stage": "dedupe", "rule": "same_audio", "detail": f"same bytes as {seen_sha[sha]}"})
        else:
            seen_iv[iv], seen_sha[sha] = r["id"], r["id"]
            kept.append(r)
    return kept, rejects


def main():
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--in", dest="inp", type=Path, required=True)
    ap.add_argument("--audio-dir", type=Path, required=True)
    ap.add_argument("--out", type=Path, required=True)
    a = ap.parse_args()
    # dedupe needs every record at once, so a re-run recomputes from scratch instead of resuming
    kept, rejects = run([json.loads(l) for l in open(a.inp, encoding="utf-8") if l.strip()], a.audio_dir)
    a.out.mkdir(parents=True, exist_ok=True)
    (a.out / "records.jsonl").write_text("".join(json.dumps(r, ensure_ascii=False) + "\n" for r in kept), encoding="utf-8")
    (a.out / "rejects.jsonl").write_text("".join(json.dumps(x, ensure_ascii=False) + "\n" for x in rejects), encoding="utf-8")


if __name__ == "__main__":
    main()
```
